## 已查明的缺口

1. “识别／确认论文文件角色”仍在命令面板、src/document_roles.js:134注册。任务助手只走任务→项目→范围→补充→预览，没有角色复用/调整步骤，项目文件范围还是单选；任务附件让AI稍后读file_roles，不能代替用户可见的角色确认。v0.9.59到v0.9.60相关文件无差异，现有有限历史不证明近期删掉过该流程。用户当前宿主未实测，不能归因未重载。

3. 现有paper_background.py的SQLite已有papers(id,revision,entries)、aliases(root,owner,paper_id)、personal。P条目仅支持kind/text/evidence/source，完整数组替换和revision CAS；可承载论文约束/背景，不能把机器角色藏进文本。alias中的owner是审核状态位置，不是角色登记owner。
